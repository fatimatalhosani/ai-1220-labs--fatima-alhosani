# Backlog — <LabLoans>

## Items
- [F] Lab staff need to record when equipment is borrowed and who borrowed it.
- [F] Lab staff need to see which equipment is currently on loan and when it is due.
- [F] Borrowers need to receive a reminder before borrowed equipment becomes overdue.
- [F] Lab staff need to record when borrowed equipment is returned.
- [F] Lab staff need to identify equipment that is overdue.
- [F] Lab staff need to view the borrowing history of each item.
- [F] Lab staff need to receive a weekly report showing every equipment loan that is still open.
- [F] Borrowers need to receive a reminder before borrowed equipment becomes overdue.
- [F] Lab staff need to search for a loan by borrower or equipment item.
- [NF] Loan information should be displayed to authorised users within three seconds.
- [NF] Borrowing and return records must be available to authorised lab staff whenever the laboratory is operating.
- [NF] Personal information about borrowers must only be accessible to authorised users.

## The change
The client requested a weekly report showing every open equipment loan because most equipment goes missing during exam weeks and exams are starting soon.
I placed this new requirement near the top of the backlog because it is urgent and directly related to the main problem identified by the audit.

The new weekly report item entered Sprint 1, so the borrower reminder item was removed from Sprint 1 to keep the sprint the same size. The reminder remains in the backlog for a later sprint.
