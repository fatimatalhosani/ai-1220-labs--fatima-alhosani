# Readable diagram exports

Export the five views as PDF, SVG or PNG. Use these base names:

- `01-context`
- `02-containers`
- `03-components`
- `04-code`
- `05-dynamic`

If you export one combined PDF, put each view on a separate readable page and give the page mapping in `DESIGN.md`.

Open the exported files to check text size, arrow labels, boundaries and legends. Confirm that every export matches its editable source.
