# Editable diagram sources

Save your tool's native editable files here. You may use one file per view or a multi-page document. Examples include `.drawio`, `.mmd`, `.puml`, `.dot` or a slide/document file with editable shapes and connectors. A raster image alone is not editable diagram source.

Use the names `01-context`, `02-containers`, `03-components`, `04-code` and `05-dynamic` where possible. If one source contains multiple views, record their pages in `DESIGN.md`.

No architecture is supplied. Create your own elements and relationships from the brief.
